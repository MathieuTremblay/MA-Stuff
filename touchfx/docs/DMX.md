# TouchFX DMX profiles

Generated by `tools/dmx_profile.py`. The GDTF file `gdtf/TouchFX@TouchFX.gdtf` contains both modes.

Default patch: **sACN universe 100, address 1** (Art-Net: universe 99, since Art-Net counts from 0).

Discrete channels (effect, scene, palette, mirror, speed, mode) use the same layout: **0-9 = keep** (no change, the panel stays in charge), then equal slots from 10 to 249, **250-255 = keep** (on the Advanced palette channel: **use the DMX colours** from the Low/Mid/High instances).

TouchFX follows *last change wins*: a channel only takes over when its DMX value changes, so the touch panel and the console can both be used. With **DMX LOCK** on, DMX always wins.

## Effect parameters (Param 1-4)

| Effect | Param 1 | Param 2 | Param 3 | Param 4 |
|---|---|---|---|---|
| Fluid | Size | Force | Swirl | Trail |
| Particles | Amount | Size | Speed | Trail |
| Kaleido | Brush | Rotation | Zoom | Trail |
| Lasers | Spread | Rotation | Swing | Width |
| Strobe | Flash length | Size | Rate (1/4..8 per beat) | - |
| Sparkles | Amount | Size | Twinkle | Spread |

Basic mode's *Param 1* is the effect's Param 1 (size / amount).

# TouchFX DMX profiles

Generated by `tools/dmx_profile.py`. The GDTF file `gdtf/TouchFX@TouchFX.gdtf` contains all three modes (Basic, Advanced, Full v2).

Default patch: **sACN universe 100, address 1** (Art-Net: universe 99, since Art-Net counts from 0).

Discrete channels (effect, scene, palette, mirror, speed, mode) use the same layout: **0-9 = keep** (no change, the panel stays in charge), then equal slots from 10 to 249, **250-255 = keep** (on the Advanced palette channel: **use the DMX colours** from the Low/Mid/High instances).

TouchFX follows *last change wins*: a channel only takes over when its DMX value changes, so the touch panel and the console can both be used. With **DMX LOCK** on, DMX always wins.

**FLASH scenes** (stored as FLASH on the panel) stay on while the Scene channel stays on them; moving the channel away (to Keep / 0 or another scene) snaps everything back to what was running before.

Two ways to work: the console programs the look with these channels, or it fires TouchFX's own cues with **Song** + **Cue** (cue number x 10). *Last change wins* applies as in v1; with **DMX LOCK** the console always wins. When the Effect channel changes, the effect keeps its own TouchFX settings; a Mode / Option / Param only takes over when its DMX value changes.
